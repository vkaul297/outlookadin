# outlookadin
An outlook addin that allows me to create templatized emails based on a job function.
These templatized emails, automatically add a specific bcc email to the email and also adds a invisible unique tracking code to track the whole conversation. The code is specific to each template. You are able to add this add-in to both classic and the browser based outlooks.
The add-in is powered by a confguration file or a backend service.
