Inline Configuration Example

This shows how to embed all configuration directly in HTML - zero external dependencies!

Benefits of Inline Configuration

  • ✅ Zero external file dependencies - everything in one HTML file
  • ✅ No fetch() required - no CORS issues
  • ✅ Works offline - can be saved and used locally
  • ✅ Faster load times - no additional HTTP requests
  • ✅ Portable - single file contains everything
  • ✅ Perfect for static hosting - deploy anywhere

How to Use in Your Add-in

// Modify loadConfiguration() in taskpane.js:

async loadConfiguration() {
    try {
        // Try inline config first
        const configElement = document.getElementById('config-data');
        if (configElement) {
            const config = JSON.parse(configElement.textContent);
            this.templates = config.templates || [];
            this.settings = config.settings || {};
            return;
        }

        // Fallback to external file
        const response = await fetch('../../config/templates.json');
        const config = await response.json();
        this.templates = config.templates;
        this.settings = config.settings;
    } catch (error) {
        this.loadDefaultConfiguration();
    }
}

Deployment Options

With inline config, you can deploy to:

  • Netlify - Drag & drop this file
  • GitHub Pages - Push to repository
  • Vercel - Deploy with one command
  • Cloudflare Pages - Free unlimited hosting
  • Azure Static Web Apps - Microsoft ecosystem
  • AWS S3 - Enterprise hosting

No backend server required! All processing happens client-side via Office.js API.
